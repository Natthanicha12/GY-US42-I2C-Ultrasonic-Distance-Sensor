# GY-US42 I2C Ultrasonic Distance Sensor

**🎯 Project Overview**
Developed a wireless distance measurement system based on **ESP8266** and **Arduino** platforms.  
The system utilizes the **GY-US42 I2C ultrasonic sensor** for precise distance sensing and transmits the measured data via Wi-Fi for remote monitoring and data logging.

## 🔧 System Implementation

-   Integrated the **GY-US42 ultrasonic distance sensor** using I2C communication.
-   Implemented distance measurement processing on ESP8266 / Arduino platforms.
-   Transmitted real-time distance data via Wi-Fi.
-   Designed the system for stable and continuous measurement.

## 📊 Data Logging and Analysis

-   Distance data are automatically logged and exported to **Excel format**.
-   The recorded dataset is used for:
    -   Performance analysis
    -   Trend monitoring
